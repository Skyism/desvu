# Self-hosted fonts

The design brief requires these self-hosted rather than CDN-loaded. They are here; the
CDN `<link>` in `index.html` can be deleted.

## Usage

Import `fonts.css` **once**, from the renderer entry, **before** `tokens.css`:

```ts
import './styles/fonts.css'   // or '/fonts/fonts.css'
import './styles/tokens.css'
```

Do not add `@font-face` rules anywhere else, and do not hand-edit `fonts.css` — it is
generated by `app/scripts/fetch-fonts.mjs`.

## What's here

| File | Family | Axis | Style |
|---|---|---|---|
| `cormorant-normal-latin.woff2` | Cormorant | `300–700` | normal |
| `cormorant-normal-latin-ext.woff2` | Cormorant | `300–700` | normal |
| `cormorant-italic-latin.woff2` | Cormorant | `300–700` | italic |
| `cormorant-italic-latin-ext.woff2` | Cormorant | `300–700` | italic |
| `dm-sans-normal-latin.woff2` | DM Sans | `100–1000` | normal |
| `dm-sans-normal-latin-ext.woff2` | DM Sans | `100–1000` | normal |

**223 KB total.** Roles are set by the brief: Cormorant for reflection and prose surfaces,
DM Sans for tools, numbers and tables.

## Three decisions worth knowing

**These are variable fonts, not static instances.** Requesting `wght@300;400;500` from
Google downloads *the same bytes three times* — 16 files, 489 KB, for what is really 6
files. Declaring the full axis instead is both smaller and strictly more capable: any
weight in range is available, not just the three the comp happened to use. Use
`font-weight: 450` freely if a surface wants it.

**latin + latin-ext only.** Cyrillic, Greek and Vietnamese subsets are dropped. The
wordmark's `è` is U+00E8, inside plain latin. If the app ever needs another script, add
the subset to `KEEP` in the fetch script and re-run.

**DM Sans italic is deliberately absent.** In this design language italic is *always*
Cormorant — it marks an estimate or an aside (`~340 cal · 12g`, `written Sunday, 6am`).
DM Sans italic appears nowhere in the approved comp and would have cost 117 KB, more than
half the total payload. If a surface genuinely needs it, delete the skip branch in
`app/scripts/fetch-fonts.mjs` and re-run.

Note the consequence: applying `font-style: italic` to DM Sans text will produce a
browser-synthesized oblique, which looks wrong. That is a signal you have reached for the
wrong family, not a bug to work around.

## Provenance and licence

Fetched from the Google Fonts CSS2 API by `app/scripts/fetch-fonts.mjs`; `manifest.json`
records exactly what was downloaded. Both families are licensed under the
[SIL Open Font License 1.1](https://openfontlicense.org), which permits self-hosting and
redistribution as part of an application.

To refresh:

```bash
node app/scripts/fetch-fonts.mjs <google-css-file> app/src/renderer/public/fonts
```
